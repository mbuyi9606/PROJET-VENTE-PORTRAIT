# PROJET-VENTE-PORTRAIT
un projet django pour l'atelier pratique

Le projet consiste à développer une plateforme de vente de portrait, elle sera constituée de trois onglets qui sont : 
•	Accueil : cet onglet contiendra trois parties qui sont :
-	Le header qui contiendra les informations essentielles de la plateforme
-	Le body qui contiendra trois portraits comme échantillons avec quelques descriptions de ces portraits
-	Le footer qui contiendra les informations sur les adresse et les contacts.

•	Les portraits : dans cette page nous n’aurons que les portraits et leurs descriptions qui sont : le prix et les libellés. Nous y en aurons 10 portraits et un footer.

•	A propos : dans celui-ci nous aurons les informations sur la plateforme tels que :
-	L’historique 
-	Les contacts et les adresse

•	Admin : une page ou nous pouvons publiés ces portraits pour qu’ils apparaissent sur le blogue. Nous aurons un bouton pour la publication, une liste des portraits ayant à chacun un bouton de modification, un bouton de suppression.
